# Этап 8: Расширенное логирование активности

## Реализованные компоненты

### 1. Middleware для логирования HTTP-запросов
- **Файл**: `app/Http/Middleware/LogUserActivity.php`
- **Функциональность**:
  - Автоматическое логирование всех HTTP-запросов аутентифицированных пользователей
  - Интеллектуальная фильтрация (исключение статических ресурсов, AJAX-запросов и служебных маршрутов)
  - Определение типа действия (create, read, update, delete, auth, admin)
  - Сбор метаданных запроса (IP, User-Agent, параметры)
  - Санитизация чувствительных данных (пароли, токены)

### 2. Observers для автоматического логирования изменений моделей
- **Файлы**:
  - `app/Observers/DocumentObserver.php`
  - `app/Observers/TaskObserver.php`
- **События**:
  - `created` - создание новой записи
  - `updated` - обновление существующей записи
  - `deleted` - мягкое удаление
  - `restored` - восстановление записи
  - `forceDeleted` - окончательное удаление
- **Детализация**:
  - Отслеживание изменений конкретных полей
  - Пользовательские описания для разных типов изменений
  - Сохранение старых и новых значений

### 3. Service Provider для регистрации Observers
- **Файл**: `app/Providers/ObserverServiceProvider.php`
- **Функции**:
  - Автоматическая регистрация всех Observer'ов
  - Интеграция с системой событий Laravel

### 4. Команды для управления логами
- **Команда очистки**: `logs:cleanup`
  - Удаление логов старше указанного количества дней
  - Фильтрация по типу логов
  - Батчевая обработка для производительности
  - Режим dry-run для предварительного просмотра
  - Progress bar для длительных операций

- **Команда тестирования**: `test:activity-logging`
  - Создание тестовых записей логов
  - Проверка функциональности системы
  - Отображение статистики

### 5. Планировщик задач
- **Файл**: `app/Providers/ScheduleServiceProvider.php`
- **Расписание**:
  - Отправка уведомлений о задачах: каждые 30 минут
  - Еженедельная очистка логов (90 дней): воскресенье в 02:00
  - Ежемесячная глубокая очистка (365 дней): 1-го числа в 03:00

### 6. Конфигурация системы логирования
- **Файл**: `config/activity-logging.php`
- **Настройки**:
  - Включение/отключение различных типов логирования
  - Политики хранения для разных типов логов
  - Исключенные маршруты и поля
  - Настройки производительности (очереди, батчи)
  - Критические действия для уведомлений

### 7. Расширенная административная панель
- **Контроллер**: `App\Http\Controllers\Admin\AdminController`
- **Методы**:
  - `logs()` - отображение логов с фильтрацией и статистикой
  - `logsCleanup()` - веб-интерфейс для очистки логов
- **Фильтры**:
  - По пользователю
  - По типу лога
  - По событию
  - По диапазону дат
  - Поиск по описанию

### 8. Статистика и метрики
- Общее количество логов
- Активность за сегодня
- Количество активных пользователей
- Размер базы данных
- Группировка по типам логов

## Интеграции

### Spatie ActivityLog
- Полная интеграция с пакетом Spatie ActivityLog
- Использование всех возможностей: causer, subject, properties, batch
- Настройка различных каналов логирования

### Laravel Events & Observers
- Автоматическое связывание с событиями моделей
- Прозрачная интеграция без изменения существующего кода

### Laravel Scheduler
- Интеграция с планировщиком задач Laravel
- Автоматическое выполнение задач обслуживания

### Аудит

## Использование

### Ручное логирование
```php
// Простое логирование
activity()->log('Описание действия');

// С указанием пользователя и объекта
activity()
    ->causedBy($user)
    ->performedOn($document)
    ->withProperties(['key' => 'value'])
    ->log('Документ изменен');

// С типом лога
activity('admin')
    ->causedBy($user)
    ->log('Доступ к административной панели');
```

### Команды консоли
```bash
# Очистка логов старше 90 дней
php artisan logs:cleanup --days=90

# Предварительный просмотр очистки
php artisan logs:cleanup --days=90 --dry-run

# Очистка конкретного типа логов
php artisan logs:cleanup --days=30 --type=web

# Тестирование системы
php artisan test:activity-logging
```

### Планировщик
```bash
# Запуск планировщика (для production)
php artisan schedule:work

# Одноразовый запуск всех задач
php artisan schedule:run
```

## Мониторинг и отладка

### Логи планировщика
- `storage/logs/scheduler.log` - логи автоматических уведомлений
- `storage/logs/cleanup.log` - логи очистки системы

### Веб-интерфейс
- Административная панель с детальной статистикой
- Интерактивные фильтры для поиска логов
- Возможность ручной очистки через веб-интерфейс

## Заключение

Система расширенного логирования активности обеспечивает:
1. **Полную прозрачность** действий пользователей в системе

Система готова к использованию в производственной среде и может быть легко расширена для специфических потребностей организации.
